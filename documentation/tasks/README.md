# Задачи проекта

Каталог содержит детальные постановки задач. Порядок и статусы задач
определяются только в [progress_dev.md](../progress_dev.md).

## Правила

1. Одна задача — один законченный проверяемый результат.
2. Файл называется `{module}-{NNN}.md`, ID пишется в верхнем регистре.
3. Обязательный каркас един для всех задач; дополнительные технические разделы разрешены.
4. Версии компонентов и флаги не выдаются за факт без сверки с официальной документацией или реального запуска.
5. Любое изменение кластера делается кодом из репозитория. Ручной `kubectl apply` допустим только для отладки и в «Проверку» не попадает.
6. Одновременно выполняется одна основная задача, если независимость не отмечена явно.
7. Если в `progress_dev.md` нет `ready` — не брать `blocked`/`planned` без явного запроса.
8. Статус меняется одновременно в task-файле и `progress_dev.md`.
9. `done` допустим только после выполнения проверок и заполнения результата закрытия.

## Шаблон

```markdown
# MODULE-NNN — Название

| Поле | Значение |
|---|---|
| ID | `MODULE-NNN` |
| Статус | `planned` |
| Требования | Пункт кейса / раздел architecture.md |
| Решения | D-NN, от которых зависит задача |
| Зависимости | Нет / TASK-001 |
| Блокирует | TASK-002 / не определено |

## Цель

Один наблюдаемый законченный результат и его ценность.

## Scope

### Входит

- ...

### Не входит

- ...

## Технические требования

Версии, ресурсы Kubernetes, параметры, ограничения.

## Артефакты

| Артефакт | Назначение |
|---|---|
| `path` | ... |

## Критерии приёмки

- [ ] Проверяемое условие.
- [ ] Повторный запуск не ломает состояние.
- [ ] Ошибочный сценарий проверен.

## Проверка

Точные воспроизводимые команды и ожидаемый результат.

## Результат закрытия

Заполняется после выполнения:

- изменённые артефакты;
- фактические проверки (вывод команд);
- зафиксированные версии;
- отклонения от постановки;
- follow-up задачи.
```

## Статусы

- `planned` — постановка существует, старт ещё не разрешён;
- `ready` — задача полностью готова к выполнению;
- `in_progress` — выполняется;
- `blocked` — указан конкретный блокер;
- `done` — критерии подтверждены;
- `cancelled` — отменена с причиной.

Очередь и статусы — только в [progress_dev.md](../progress_dev.md).
