## Цель

Репозиторий и архив готовы к сдаче: эксперт клонирует репозиторий без
авторизации, архив соответствует формальным требованиям кейса.

## Scope

### Входит

- проверка публичности репозитория и `git clone` без учётных данных;
- проверка требований к репозиторию: ветка `main`, обязательные материалы,
  отсутствие секретов;
- сборка архива `<Фамилия>.zip` с `Ссылка.txt` и `Паспорт.pdf`.

### Не входит

- загрузка архива на площадку хакатона: выполняется участником через форму
  на сайте, в репозитории не фиксируется. Фамилия участника в репозиторий не
  записывается (персональные данные).

## Технические требования

| Параметр | Требование кейса |
|---|---|
| Формат и объём архива | ZIP или RAR, не более 18 МБ |
| Имя архива | Фамилия участника, как при регистрации |
| Файлы внутри | `Ссылка.txt` (только ссылка на репозиторий), `Паспорт.pdf` (не более 4 страниц, не более 15 МБ) |
| Репозиторий | Публичный, ветка `main`, без изменений после 04.10.2026 23:59 |

## Критерии приёмки

- [x] Репозиторий публичный, ветка по умолчанию — `main`.
- [x] `git clone` выполняется без учётных данных.
- [x] В репозитории есть все обязательные материалы: манифесты и автоматизация, конфигурация Gateway API, мониторинга, логирования, README.
- [x] В репозитории нет секретов.
- [x] Архив: ZIP, два файла с требуемыми именами, объём меньше 18 МБ.
- [x] CI на итоговом коммите зелёный.
