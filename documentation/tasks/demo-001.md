## Цель

Одна команда, которая за 5–7 минут проводит эксперта по всему решению с
понятными пояснениями на русском: что сейчас происходит, какой командой
это проверить самостоятельно и куда посмотреть в Grafana. Пригодится и как
сценарий живой демонстрации на очном финале.

## Сценарий

1. **Обзор:** версии, узел, компоненты; ссылки на Grafana / Prometheus /
   Argo CD и как получить пароли.
2. **Gateway API:** `curl` на `/`, `/v2`, `/canary` (распределение 80/20),
   по hostname, HTTPS с проверкой сертификата; rate limit → 429.
3. **Мониторинг:** PromQL-запросы с результатом (targets UP, RPS по
   маршрутам, p95), SLO и остаток бюджета ошибок.
4. **Логирование:** запрос с уникальной меткой → найден в Loki (LogQL).
5. **Трейсинг:** этот же запрос → трейс в Tempo (если TRACE-001 сделана).
6. **Хороший релиз:** `release-good` — веса растут, анализ проходит.
7. **Плохой релиз:** `release-bad` — всплеск 5xx, автооткат, ответы снова
   от стабильной версии; аннотации на дашборде.
8. **Итог:** что проверено, ссылки на дашборды с нужным временным окном.

## Scope

### Входит

- `scripts/demo.sh`, цель `make demo`;
- режимы: интерактивный (пауза «Enter — дальше» между шагами) и
  `--auto` (без пауз — для записи и для CI);
- цветной вывод, каждая проверка печатает и команду, и результат —
  эксперт может повторить вручную;
- `make demo` не меняет итоговое состояние: после сценария версия
  приложения возвращается к стабильной (`release-reset`).

### Не входит

- запись видео/GIF (можно сделать вручную для паспорта).
