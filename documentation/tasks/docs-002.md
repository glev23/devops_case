## Цель

Корневой `README.md`, по которому эксперт без доступа к нашей
инфраструктуре понимает архитектуру, разворачивает решение на чистой
Ubuntu 24.04 и проверяет каждый обязательный компонент. Это единственный
источник команд развёртывания и проверки (documentation/README.md).

## Scope

### Входит

- все 13 обязательных пунктов README из кейса;
- требования кейса к README из пп. 1, 3, 4, 5: версия Kubernetes, способ
  создания кластера, ОС тестирования, все дополнительные компоненты со
  способом установки; реализация Gateway API, её версия и используемые
  ресурсы; какие метрики собираются и как проверить; какие логи
  собираются, куда поступают и как проверить;
- архитектурная схема (Mermaid, рендерится на GitHub);
- автоматическая проверка (`make verify`, `make demo`) и ручная (curl,
  PromQL, LogQL) с ожидаемым результатом;
- доступ из браузера: записи hosts, команды получения паролей;
- дополнительные возможности с командой проверки для каждой;
- известные ограничения (architecture.md §12);
- бейдж CI.

### Не входит

- прогон по README на чистой ОС — QA-001;
- скриншоты и паспорт — QA-001, PASSPORT-001.

## Технические требования

- Версии берутся из `ansible/group_vars/all.yml` и с работающего кластера
  (`helm list -A`, образы подов), а не из памяти.
- Каждая ручная команда из README выполнена на стенде, вывод совпадает с
  описанным.
- Формальный язык, без маркетинговых формулировок.

3. `grep` по версиям: каждая версия из README есть в `group_vars/all.yml`
